## Dataset

The project analyzes the [Smart Meter Electricity Consumption Dataset](https://www.kaggle.com/datasets/ziya07/smart-meter-electricity-consumption-dataset), published on Kaggle by account `ziya07`. The listing displays **CC0: Public Domain** and Version 1. The listing does not identify an upstream measurement campaign, separate original creator, collection hardware, or inverse-scaling procedure.

The public repository should therefore contain no raw dataset file and no full dataset-derived validation vectors. Users should download the data from the source listing and follow its current terms. Dataset attribution is retained as good scholarly practice even though CC0 does not require attribution.
